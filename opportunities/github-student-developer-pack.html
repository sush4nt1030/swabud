Student Programs & Perks

GitHub Student Developer Pack

Always open

By GitHub Education

A bundle of developer tools, cloud credits and learning platforms that are free or discounted for students, including GitHub Pro.

Who can apply

Students who verify their student status with GitHub. Some partner offers have their own age limits.

Dates

Always open while you are a student.

How to apply

  1. Create a GitHub account with your college email if you have one.
  2. Apply for student benefits from your GitHub education settings.
  3. Upload proof of enrolment if asked.
  4. Activate the partner offers you need.
SWABUD noteMany offers are time-limited trials or credits, so activate them when you are ready to use them.

What it costs and what you get

Cost: Free for verified students

Benefits: GitHub Pro, a free JetBrains subscription, Azure credit, GitHub Copilot Student for verified students, and more

Before you apply

  • Open the official page and confirm the dates in Nepal time.
  • Read the eligibility rules in full, including age and country.
  • Never pay an agent or a third party to apply. Official programmes say clearly if there is a fee.
  • Save a copy of your application and any confirmation email.
